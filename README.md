# Python Unit Converter

A practical Python project designed to convert different units such as length, weight, and temperature.  
This project is part of my journey to build real-world tools, improve my coding skills, and gain hands-on experience with Python.

## Features
- Convert length units (meters → kilometers, miles, feet)
- Convert weight units (grams → kilograms, pounds)
- Convert temperature units (Celsius → Fahrenheit, Kelvin)
- Clean and simple CLI interface
- Loop-based menu system
- Easy to extend with new unit categories

## Installation & Usage

1. Clone the repository:
   git clone https://github.com/miladzendehboudi/unit-converter

2. Navigate to the project folder:
   cd unit-converter

3. Run the script:
   python main.py
